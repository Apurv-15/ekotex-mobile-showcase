# Ekotex — Multi-Branch Field & Inventory App

> **Live Web Portal (Vercel):** [https://ekotex-mobile-demo.vercel.app](https://ekotex-mobile-demo.vercel.app)  
> **Client:** Ekotex Electrificient  
> **Tech Stack:** React Native (Expo), Supabase PostgreSQL, FlashList, Offline-First Delta Sync

---

## 📌 Project Overview
Ekotex is a cross-platform enterprise React Native app automating product warranty QR tracking, field technician visits, and multi-branch real-time inventory synchronization. Built with an offline-first delta caching architecture, it ensures 100% field operation availability even in low/no-connectivity environments.

---

## 🚀 Key Engineering Highlights
* **Offline-First Delta Sync Engine:** Queues transactions locally and syncs automatically when network reconnects.
* **QR Warranty System:** Instant scan-to-verify warranty status for field technicians.
* **60fps Virtualized Lists:** High-efficiency FlashList rendering for thousands of inventory SKUs.
* **Multi-Branch RLS Isolation:** Strict database-level row isolation across enterprise branches.
